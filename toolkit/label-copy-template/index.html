Label Copy Template

A free, ready-to-use template for independent Indian artists. Read it here, or make your own copy to fill in.

Label copy is the text information that appears on physical releases (CDs, vinyl, cassettes) and in distribution system metadata. Correct label copy is required by distributors, pressing plants, and retailers.

What's inside this template

  • What Is Label Copy?
  • Release Identification
  • Track Listing
  • Total Duration
  • Number of Tracks
  • Production Credits
  • Artwork & Packaging Credits
  • Thank you / Acknowledgements
  • Standard Copyright Line
  • Parental Advisory — Explicit Content
  • Distributor Line
  • Physical Packaging Checklist
  • UPC |
